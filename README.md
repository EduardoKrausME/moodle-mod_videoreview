# Video Peer Review (`mod_videoreview`)

Video Peer Review is a Moodle activity for timestamped video feedback and criterion-based assessment. A teacher can
publish one common video for evaluation or let each learner submit a video that is reviewed by the teacher and/or
assigned peers.

## Main features

- Common-video and student-submission modes.
- Uploaded videos, direct video URLs, YouTube and Vimeo links.
- Timestamped comments that seek the player back to the commented moment.
- Numeric and concept-based criteria, with optional criterion feedback.
- Automatic peer allocation with a configurable number of colleagues per learner.
- Anonymous peer-review display for students while teachers retain full audit visibility.
- Delayed release of received reviews until a configured date.
- Video-viewing progress stored per evaluator and reviewed video.
- Reports for reviews received, reviews performed, progress and grades.
- Gradebook integration for student-submission mode.
- Completion rules for submitting a video and completing assigned reviews.
- Backup/restore and Privacy API support.

## Requirements

Moodle 4.4 or later.

## Installation

Copy the `videoreview` directory to `mod/videoreview` and complete Moodle's upgrade process.
